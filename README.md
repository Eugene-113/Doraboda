## 소개
하루를 돌아보며 감정과 감상을 기록하는 일기 어플. 음악과 함께 일기를 쓸 수도 있다.

## 기능
- 오늘의 감정과 한마디 기록
- 뮤직 플레이어
- 랜덤 명언
- 지금까지의 감정을 모아 통계
- 데이터 백업 및 불러오기

## 개발기간
2025/01 ~
